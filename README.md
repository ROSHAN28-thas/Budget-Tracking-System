# Tamil Nadu District Family Budget Dataset

This repository contains a district-wise family budget dataset for Tamil Nadu.

## Dataset Details

- State: Tamil Nadu
- Districts: 38
- Family Size: 4
- Income Class: Middle
- Data Type: Estimated / Prototype Data

## Expense Categories

The dataset contains estimated monthly expenses for:

- Food
- Rent
- Electricity
- Transport
- Education
- Healthcare
- Other Expenses

## Purpose

This dataset is created as a supporting dataset for a family budget
calculation project. The values are intended for educational and
prototype purposes.

## Important Note

The values in this dataset are estimates and should not be treated
as official government district-wise household expenditure figures.

## Reference

Government of India, Ministry of Statistics and Programme Implementation
(MoSPI), Household Consumption Expenditure Survey (HCES) 2023-24.
